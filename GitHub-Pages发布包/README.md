# 域商运营：电商区域履约与网点规划

基于 Olist 巴西电商公开历史订单的企业场景模拟项目。围绕区域运营分析、履约排查、需求预测评估及配送服务点规划提供可操作的工作台。项目使用历史公开数据，不连接真实商家生产系统。

## 功能

- 查询 15,441 条有效订单，按日期、24 个服务区和逾期状态筛选，分页查看及导出完整 CSV。
- 展示区域订单分布、周需求趋势和符合最小样本量的履约排查区域。
- 比较 5 种需求预测方法，严格按时间分离验证期与测试期，以验证 WAPE 选择候选方法。
- 在 24 个候选点中选择 1—8 个网点，对比热点布局和需求加权优化布局。
- 调整重点区域权重，使用 Web Worker 穷举全部候选组合，实时求解加权最近球面距离最小的全局最优方案。
- 按原始订单坐标回放平均距离、90 分位距离和 3 / 5 公里覆盖率。
- 保存及下载自定义方案；方案仅保存在当前浏览器 localStorage，最多 30 个，不会共享给其他访客。

## 运行与发布

本仓库是无需编译的静态网站。以任意静态 HTTP 服务运行仓库根目录即可预览；直接双击 HTML 文件会受浏览器本地数据读取限制。

GitHub Pages 设置：进入仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/(root)**，保存。`.nojekyll` 保留原样的静态资源。

资源地址均使用相对路径，支持 GitHub Pages 的仓库子目录。浏览器需要支持 Web Worker、localStorage 及现代 JavaScript。

## 数据与方法

- 研究区域：巴西圣保罗市；订单区间为 2017-01-02 至 2018-08-26。
- 24 个区域由训练期订单坐标聚类得到，候选服务点为训练期邮编代表坐标。
- 最终回放窗口：2018-07-02 和 2018-07-30 各自起 4 周，合计 2,305 单。
- 验证期选择近 8 周均值预测；测试期 WAPE 为 35.41%。没有根据最终测试表现重新选择模型。
- 5 网点优化方案的订单加权平均最近距离为 5.26 公里，热点布局为 6.74 公里，减少 22.03%。这属于本数据的空间回放结果，不代表真实配送成本或时效收益。
- 预计算方案保留原 SciPy MILP 求解记录；在线新建方案标明精确组合穷举求解器，不冒用 MILP 元数据。

## 指标限制

球面距离不是路网里程。尚未加入物业、容量、租金、车辆或道路约束，不能直接形成实际开店指令。逾期分析为事后履约排查，不是下单时风险预测，也不证明网点不足导致逾期。部分订单缺少商品记录，在需求统计中仍被保留。
